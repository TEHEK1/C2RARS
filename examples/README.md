Примеры использования C2RARS для преобразования C кода в RARS-совместимый RISC-V assembly.


## Как использовать

### Шаг 1: Скомпилировать пример

```bash
cd /Users/kamir22/Kurs/build
./src/cli/c2rars -i ../examples/02_arithmetic/02_arithmetic.c -o 02_arithmetic.asm
```

### Шаг 2: Открыть в RARS

1. Запустить RARS
2. File → Open → выбрать `arithmetic.asm`
3. Нажать Run → Assemble
4. Нажать Run → Go

### Шаг 3: Увидеть результат

Вывод появится в консоли RARS.

## Список примеров

### 01_hello.c - Hello World
Простейший пример вывода строки.

**Демонстрирует:**
- Базовый вывод текста
- Использование RARS syscall `print_string`

**Ожидаемый вывод:**
```
Hello, RARS!
```

---

### 02_arithmetic.c - Арифметические операции
Демонстрация базовых математических операций.

**Демонстрирует:**
- Сложение, вычитание, умножение
- Вывод чисел
- Форматированный вывод

**Ожидаемый вывод:**
```
Arithmetic Operations Demo
==========================
a = 15, b = 27
a + b = 42
a - b = -12
a * b = 405
```

---

### 06_multifile - Раздельная компиляция
Пример многофайловой программы: `main.c` вызывает функцию из `hi.c`.

**Демонстрирует:**
- Раздельная компиляция нескольких единиц трансляции
- Вызов функций между файлами

**Ожидаемый вывод:**
```
Hello, world!
```

---

### 07_string_input.c - Ввод строк и расширенный I/O
Интерактивный пример: чтение имени и числа с клавиатуры, вывод в разных форматах.

**Демонстрирует:**
- Ввод строки (`read_string`)
- Ввод числа (`read_int`)
- Вывод числа в hex (`print_int_hex`) и двоичном виде (`print_int_bin`)

**Ожидаемый вывод (при вводе "Alice" и 42):**
```
Enter your name: Alice
Hello, Alice
You entered: 42
Hex: 0x0000002a
Bin: 0b00000000000000000000000000101010
```
