# C2RARS

Транслятор программ, скомпилированных кросс-компилятором языка Си (GCC), в ассемблерный код, совместимый с учебным симулятором [RARS](https://github.com/TheThirdOne/rars).

**Курсовой проект** — НИУ ВШЭ, Факультет компьютерных наук, 2025–2026  
**Автор:** Кашапов А.В., БПИ231

---

## Описание работы

Стандартный ассемблерный код, генерируемый компилятором GCC для архитектуры RISC-V, не может быть напрямую выполнен в симуляторе RARS из-за различий в системных вызовах, поддерживаемых директивах и организации памяти. 

Пайплайн C2RARS решает эту проблему, выполняя трансляцию кода по следующей схеме:
```text
[ Исходный код на Си ] ➔ GCC ➔ [ Ассемблер GCC ] ➔ C2RARS ➔ [ Ассемблер RARS ] ➔ Запуск в RARS
```

### Основные возможности:
* **Аппаратная поддержка плавающей точки:** Поддерживаются типы `int`, `float`, `double` с использованием инструкций FPU (ISA `RV32IMFD`, ABI `ilp32d`).
* **Библиотека ввода-вывода:** Предоставляется заголовочный файл `rars_io.h` — обертка над системными вызовами RARS для выполнения операций ввода/вывода в Си-коде.
* **Двухплатформенная компиляция:** Код, написанный с использованием `rars_io.h`, может быть скомпилирован как для нативного исполнения на хост-машине (для предварительной отладки), так и для симулятора RARS.

## Быстрый старт

### 1. Зависимости

Для сборки и работы утилиты требуются:

| Инструмент | Назначение |
|---|---|
| **CMake** (>= 3.15) | Система сборки |
| **Flex** & **Bison** (>= 3.2) | Лексический и синтаксический анализаторы |
| **RISC-V GCC** | Кросс-компилятор (`riscv64-unknown-elf-gcc` или `riscv64-elf-gcc`) |
| **Java** (>= 11) | *Опционально:* для запуска симулятора RARS и тестов |

**Установка зависимостей:**
* **Ubuntu/Debian:** `sudo apt install cmake flex libfl-dev bison gcc-riscv64-unknown-elf`
* **macOS (Homebrew):** `brew install cmake flex bison riscv-elf-gcc`

### 2. Сборка проекта

```bash
mkdir -p build
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```
Исполняемый файл будет находиться по пути: `build/src/cli/c2rars`

### 3. Установка (опционально)
```bash
sudo cmake --install build --prefix /usr/local
```
Утилита `c2rars` будет скопирована в директорию бинарных файлов системы, а заголовочный файл установится в `/usr/local/include/c2rars/rars_io.h`.

## Использование

Базовая команда для трансляции исходного файла в ассемблер RARS:
```bash
c2rars program.c -o program.asm
```

Запуск полученного файла в симуляторе RARS (в консольном режиме):
```bash
java -jar rars.jar program.asm
```

### Параметры командной строки

| Флаг / Аргумент | Описание |
|---|---|
| `[file]` или `-i, --input <file>` | Входной файл (исходный код `.c` или ассемблер `.s`).|
| `-o, --output <file>`| Выходной файл `.asm` (по умолчанию: `<имя_входного_файла>.asm`) |
| `-c, --compiler <name>`| Явное указание исполняемого файла кросс-компилятора |
| `-v, --verbose` | Вывод подробной информации о процессе трансляции |
| `-h, --help` | Вывод справки |

### Определение кросс-компилятора
Программа ищет исполняемый файл GCC в следующем порядке приоритета:
1. Аргумент командной строки `-c` (например: `-c riscv64-elf-gcc`).
2. Переменная окружения `RISCV_GCC` (например: `export RISCV_GCC=riscv64-elf-gcc`).
3. Путь, автоматически определенный CMake на этапе сборки.

## Библиотека `rars_io.h`

Для взаимодействия с консолью и системными функциями RARS используется заголовочный файл `rars_io.h`, реализующий интерфейс к системным вызовам (syscalls) симулятора.

**Пример `hello.c`:**
```c
#include <c2rars/rars_io.h>

int main() {
    print_string("Hello, world!\n");
    return 0;
}
```

**Трансляция и запуск (RARS):**
```bash
c2rars hello.c -o hello.asm
java -jar rars.jar hello.asm
```

### Двухплатформенный режим (`__C2RARS__`)
При трансляции через `c2rars` утилита автоматически определяет макрос `__C2RARS__=1`. Заголовочный файл `rars_io.h` использует этот макрос для переключения реализации функций. 

Это позволяет компилировать и тестировать один и тот же исходный код как на хост-системе (используя стандартную библиотеку C), так и в симуляторе RARS, без внесения изменений в тексты программ.

**Компиляция и запуск на хост-системе:**
```bash
# Компиляция стандартным компилятором (GCC или Clang)
gcc hello.c -o hello

# Запуск скомпилированного файла
./hello
```

## Особенности трансформации кода

В процессе трансляции утилита выполняет следующие преобразования абстрактного синтаксического дерева (AST):

1. **Оптимизация адресации:** Свертка пар инструкций `lui`/`addi` (relocations `%hi`/`%lo`) в псевдоинструкцию `la`. Аналогичное преобразование применяется для инструкций загрузки и сохранения (`lw`/`sw`/`flw`/`fsw`/`fld`/`fsd`).
2. **Адаптация системных вызовов:** Замена Linux-вызовов (`ecall` 93/94) на совместимые с RARS (например, вызов завершения программы — 10). Подмена стандартных вызовов `printf`/`puts` на `print_string`.
3. **Обработка точки выхода:** Замена инструкций `ret`/`jr ra` в функции `main` на системный вызов корректного завершения программы в симуляторе.
4. **Удаление неподдерживаемых директив:** Очистка кода от директив, нераспознаваемых синтаксическим анализатором RARS (`.section`, `.align`).
5. **Реорганизация секций:** Перенос данных (`.word`, `.string`) из секции `.text` в `.data`. Размещение секции `.data` перед секцией `.text`.
6. **Выравнивание памяти:** Автоматическая вставка директив `.align 3` перед метками данных для корректной работы 8-байтовых инструкций (`fld`/`fsd`).

## Примеры и тестирование

В директории `examples/` представлены тестовые программы, демонстрирующие работу различных конструкций языка (циклы, массивы, рекурсия, операции с плавающей точкой, многофайловая компиляция).

Проект включает систему автоматического тестирования. Каждая программа компилируется нативно для хост-системы и транслируется через C2RARS. Полученные результаты побайтово сравниваются с эталонными выводами из директории `tests/expected_output/`.

**Запуск тестов:**
```bash
./scripts/test.sh                     # Запуск всех тестов
./scripts/test.sh -v                  # Запуск с подробным выводом
./scripts/test.sh --example 03_loop   # Запуск конкретного теста
```
